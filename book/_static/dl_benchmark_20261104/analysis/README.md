# Análisis del benchmark de desarrollo

Exploratory development evidence on 2024 calibration dates; not reserved-test evidence or confirmation of generalization. Seed intervals condition on this calendar.

Las tablas separan incertidumbre entre semillas, diferencias temporales de pérdidas, bootstrap de fechas y diagnósticos residuales. Los intervalos95% son marginales. Los tres grupos de contrastes temporales/diagnósticos no constituyen confirmaciones independientes. La persistencia es determinista y no representa R entrenamientos. El test de 2025–2026 no se lee ni se evalúa aquí.
