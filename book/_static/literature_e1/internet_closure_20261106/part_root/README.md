# Fuente complementaria de control de alternativas

Se consultó la página primaria de Brauneis y Sahiner, DOI
10.1007/s10690-024-09510-6, publicada online el 13/12/2024 y asignada al
volumen de 2026. La lectura alcanzó el cuerpo principal y las leyendas de
tablas; las celdas y las recetas finales no se recuperaron. Por ello se
registra una lectura parcial y no se añaden métricas ni frecuencia estricta.

Esta fuente compara MLP/LSTM y un híbrido CNN-BiLSTM con HAR y boosting.
Documenta una alternativa a la terna actual; no se seleccionó por favorecerla.
No se confunde una fuente nueva de la web con una ocurrencia de las cuatro
exportaciones nativas ni con una búsqueda ejecutada en WoS, Scopus o IEEE.
