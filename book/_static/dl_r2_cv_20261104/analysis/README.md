# Resultados de CV mensual de Filipe

CV mensual exploratoria de desarrollo en 2024. Inferencia entre semillas condicionada al calendario compartido; sin confirmación en test reservado.

Las dos representaciones se ajustan con los mismos doce cortes mensuales y diez semillas. La tabla anual reúne366fechas; la tabla semestral184fechas. Los R² se calculan agrupando las predicciones de cada trayectoria, no promediando los R² de meses aislados. Persistencia es una única trayectoria determinista; MASE usa la escala mensual registrada en cada fecha. Los contrastes dentro de cada red conservan su familia original de tres en p_holm; p_holm_global12 aplica la revisión conjunta. El complemento estadístico contiene comparaciones entre redes y persistencia, DM/HAC/HLN, diagnósticos residuales, bootstrap de fechas y sensibilidad de planificación. Sus alcances se distinguen y no certifican potencia ni generalización. No hubo ajustes nuevos ni evaluación del test.
