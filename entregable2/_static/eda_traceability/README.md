# Trazabilidad de decisiones del EDA E2

La tabla CSV es una síntesis interpretativa redactada y versionada, no una estimación estadística adicional. Cada fila enlaza evidencia, preprocesamiento, arquitectura, validación, riesgo y estado. El formato es propio hasta recibir la plantilla del Apéndice A. Las rutas de evidencia parten de `_static/` de E2.

El JSON de identidad enlaza hashes y cronología de E1. No crea un nuevo test sellado ni modifica el contrato científico.
