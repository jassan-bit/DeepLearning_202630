# Recuperación arXiv del 08/11/2026

La API se consultó con campos all:, sin filtro de fecha y con orden submittedDate descendente. query_manifest.json registra consultas, URLs paginadas, totales y hashes de Atom privado. query_membership.csv permite reproducir la unión por identificador arXiv sin versión. records.csv conserva la versión recuperada y metadatos mínimos, sin resúmenes completos. Las consultas pueden cambiar después del corte; los hashes fijan los recibos de esta recuperación, no prometen reproducir resultados futuros idénticos.

Son 1.199 apariciones, 1.004 identificadores y 195 repeticiones entre consultas. Se etiquetaron inicialmente 21 candidatos; 983 permanecen pendientes. No hay decisiones finales de inclusión ni revisión exhaustiva de los 1.004. Se realizó lectura focal de tres cuerpos: 2410.09062, 2205.07719 y 2610.03019. La búsqueda por HTML se excluye del corpus principal porque sus resultados booleanos no mostraron anidamiento consistente. Las respuestas API sí verificaron BTC como subconjunto de la consulta cripto.

Los identificadores arXiv no se suman a los grupos WoS/Scopus/IEEE: falta conciliación entre estos universos y con rondas anteriores. Un preprint no acredita por sí solo revisión por pares ni cuartil editorial.
