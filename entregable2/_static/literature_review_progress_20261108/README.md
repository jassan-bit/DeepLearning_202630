# Revisión de títulos/resúmenes y próximos pasos, 08/11/2026

Este suplemento publica únicamente agregados, método de muestreo y alertas de verificación. Conserva sin cambios el ledger de triaje inicial, los originales y las dos tablas privadas de decisiones individuales. No incluye abstracts ni citas textuales. La revisión fue asistida por IA, no doble revisión humana ni elegibilidad final por texto completo.

Se revisaron los 59 prioritarios. Se auditaron 42 de 337 exclusiones propuestas mediante 30 aleatorios y 12 adicionales de riesgo (15 títulos de riesgo, tres solapados). La muestra combinada no permite extrapolar una tasa de error a los 295 restantes. Dos registros rescatados siguen siendo secundario/incierto, no nuevos estudios incluidos.

`python scripts/build_e2_review_progress.py --check` valida agregados, límites y espejo público. Regenerar con los CSV privados requiere `--private-dir` apuntando fuera del checkout; el constructor solo exporta conteos, dos IDs de rescate y huellas de archivos, nunca cuerpos de resúmenes. El plan de fases es editorial, no un protocolo registrado ni autorización para iniciar ajustes. No se modifican protocolos ni resultados históricos.
