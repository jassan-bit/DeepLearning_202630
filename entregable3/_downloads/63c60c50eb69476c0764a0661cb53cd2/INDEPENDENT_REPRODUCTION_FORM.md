# Constancia de reproducción independiente — sin completar ni firmar

Este documento preparado con IA no acredita ejecución por una persona externa.
Debe completarlo quien realmente construya y ejecute su alcance declarado.

| Campo | Declaración de quien reproduce |
|---|---|
| Nombre y relación con el proyecto | PENDIENTE |
| Fecha, hora y zona horaria reales | PENDIENTE |
| Alcance elegido A / B / C y productos exactos | PENDIENTE |
| Fuente inmutable, commit y hashes del archivo recibido | PENDIENTE |
| SO, CPU/GPU, memoria y versiones de Docker/Python | PENDIENTE |
| Imagen base por digest e imagen final obtenida | PENDIENTE |
| Procedencia/hash de datos, pesos y artefactos usados | PENDIENTE |
| Comandos realmente ejecutados, logs y códigos de salida | PENDIENTE |
| Ausencias, pasos omitidos y desviaciones | PENDIENTE |
| CSV de diferencias y máximo por campo/unidad, ubicación y tolerancia | PENDIENTE |
| Recibos emitidos y su SHA256 | PENDIENTE |
| Uso de IA durante la ejecución/revisión | PENDIENTE |
| Conclusión propia sobre reproducibilidad del alcance elegido | PENDIENTE |
| Constancia o firma aportada por quien ejecutó | PENDIENTE |

No completar C a partir de A o B. A reconstruye agregados desde predicciones
guardadas; B genera predicciones con pesos aceptados; C reconstruye entrenamiento.
La misma tabla o fecha no es una réplica independiente por cambiar el contenedor.
La excepción docente comunicada para revisión IA de R1 no sustituye esta persona
ni amplía por sí sola el alcance acordado de reproducción humana.
