# Procedencia y exclusiones de este suplemento

Este suplemento nuevo conserva código, planes, resultados y recibos derivados.
La asistencia de IA está declarada. No concede una licencia global ni extiende
las decisiones MIT/CC BY del suplemento DOI 0.2.0 a otros materiales.

| Componente | Incluido en el suplemento de código/resultados | Alcance y límites |
|---|---|---|
| V4 y piloto CPU | Fuentes, plan previo público, solicitudes, curvas, metadatos, 1.210 predicciones derivadas, métricas y hashes de checkpoint. | La pérdida es un prototipo de desarrollo abandonado. No se activó en Render ni se publicó un ONNX nuevo. No hereda R1 de V3. |
| Checkpoints y NPZ del caso privado | No se incluyen sus bytes. | Los pesos permanecen localmente con hashes; no se infiere autorización de redistribución. El NPZ original se identifica por hash y procedencia bajo las condiciones de su fuente. No se denomina depósito de pesos o datos a sus localizadores. |
| Validación estadística controlada | Código y resultados Monte Carlo, incluidos registros comprimidos y casos adversos. | Datos sintéticos propios; no predicciones nuevas de mercado. La configuración no queda validada para confirmar. |
| Preparación de datos futuros | Identificadores, URLs, versiones/términos observados, calendarios y declaración sin completar. | Cero datasets admitidos y ninguna cotización futura obtenida. Mantener las restricciones de proveedor; una página pública no prueba derecho de redistribución o uso institucional. |
| Kit de reproducción | Código v1 y suplemento 1.1, perfiles sin firma, recibos automáticos y tablas derivadas. | No se incluye el checkout completo de 1,50 GB. Su adquisición y copia local por quien reproduce se verifican por Git y hashes, con términos originales. El perfil probado es `f5c960e`, no esta edición posterior. |
| Contenedor y dependencias | Dockerfile, lock original, lock de artefactos, hashes y reportes de instalación de 89 wheels. | Los 49.700.631 bytes de wheels y la imagen OCI local no se distribuyen aquí. Quien reproduzca obtiene las dependencias bajo sus licencias. El build/ejecución automáticos no son un concepto humano. |
| Fuentes históricas copiadas | Archivos propios del motor y módulos locales fijados por tamaño/hash, con su procedencia. | Avisos y condiciones originales conservados. No se cambia la identidad de las implementaciones ni se atribuye autoría humana de la ejecución a una IA. |

Permanecen intactos los 796 trabajos, 30 ajustes V3, 20.400 filas de transferencia,
DOI documental y cápsula 0.3.1-REVIEW. Este suplemento no contiene los 4,27 GB
del maestro, datos brutos del caso privado, checkpoints sin revisión, wheels o
una reproducción humana. Las exclusiones se mantienen explícitas aun cuando
existan hashes o URLs para su adquisición por separado.
