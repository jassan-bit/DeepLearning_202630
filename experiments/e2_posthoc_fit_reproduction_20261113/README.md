# Reproducción y ablaciones post hoc preparadas

Esta extensión está preparada y validada con datos artificiales. **Los 81 nuevos ajustes, las 18 ablaciones y la reproducción A100 aún requieren ejecución real en Colab**; ningún resultado de entrenamiento de mercado se atribuye a estas pruebas locales.

La única entrada para ejecutar el cierre es `run_e2_posthoc_fit_reproduction_colab(commit, execute=True)` del lanzador publicado en el mismo commit. Conserva `/content/entregable2_gpu_workspace/github-primary-output-v1` y el entorno A100 original. La celda realiza consultas nativas, diagnósticos sobre predictores congelados y, después, crea un checkout limpio y un entorno aislado nuevo para entrenar. El token existente del kernel/Colab pasa exclusivamente por STDIN; GitHub es el único destino persistente.

Se conserva el consentimiento previo de **80 horas totales**, el diario original de 1368 registros y todos sus cargos: quedan 18169,090972 segundos antes de esta extensión. Cada trabajo reserva su peor caso (1800 segundos por fase más 60 de sobrecarga), publica la reserva mediante CAS en un control nuevo y carga tiempo real de preparación, ejecución y copias. Una interrupción desconocida retiene la reserva y bloquea el reintento automático. Las fuentes, congelación, selección, resultados y puntero de control originales permanecen en lectura.

La reproducción usa las recetas, semillas y épocas ya congeladas: 78 ajustes neuronales y tres ajustes finales clásicos, sin repetir selección/CV. Compara tensores de pesos (o parámetros clásicos), 53 predicciones de calibración y 608 de prueba con las originales. Los seis SAE completos nuevos sirven de referencia para tres intervenciones reales: quitar preentrenamiento auxiliar; quitar el segundo encoder (queda encoder25, AE1 y la cabeza Softplus); quitar dropout (0 frente al ganador0,3). Cada intervención conserva las épocas de las fases restantes y genera nuevos pesos, curvas, configuración, costos y predicciones. El contraste usa seis semillas pareadas y bootstrap de semillas/calendario de bloques14 con10000 réplicas y Holm3.

Los objetos Git y las fuentes upstream verificadas pueden reutilizarse; el checkout de trabajo y la instalación de paquetes son nuevos. No se afirma una descarga nueva de upstreams. Si instalación, presupuesto o reproducción fallan, se conserva evidencia y se informa el estado incompleto. Los análisis son post hoc sobre un único mercado conocido; no seleccionan un ganador nuevo ni certifican generalización prospectiva.
