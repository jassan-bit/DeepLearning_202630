# Independent adversarial review of the versioned data adapter

This review did not edit `data/engine_data_v2.py`, the data proposals, or source A.
All fixtures use manufactured prices, actors and licenses inside temporary
directories, which are removed. `urllib` is blocked and acquisition/recovery
clients receive only predetermined generated bytes. No real market admission,
training, forecast, final reserve or human signature is claimed. AI assistance
is declared.

The initial extension SHA256 was
`eb3f718e2313402f66304b2b77154d3192825063d6582318825ad6f3d1b724a0`.
`INITIAL_FINDINGS.json` records two independently reproduced problems:

1. A source manifest could change `instrument=BTCUSDT` to `ETHUSDT` and
   recompute its self-hash while retaining BTCUSDT URLs, filenames and payloads.
   Preparation incorrectly admitted it as ETHUSDT.
2. Restoring an actual source-A Spot admission with the extension failed the
   strict provenance comparison because the extension unconditionally added
   new provenance keys absent from the old event.

The data owner corrected the adapter and added regression coverage. This
review then reran the same two cases with `--require-fixed`. The tested final
extension SHA256 is
`1e64a500a62b3ec803471f87a2a81161a81d0e73d2c4cce7fd17d73b2b044e60`.
`CORRECTIVE_REVIEW.json` records both checks passing:

* The instrument/filename mismatch is rejected before preparation.
* The source-A Spot manifest, four NPZ partitions, admission and recovery
  metadata are restored byte for byte without changing their original hashes.

Source A stayed at SHA256
`3851281f00fc7b43bfb681d10be988f0efc5fb3d879e6b4faab2fe4798a9d917`.
Static review also confirmed the canonical source validator runs in development
and final preparation, and in recovery-bundle validation before downloads;
checksum filenames are bound and legacy provenance shape is preserved.

The driver is a workspace QA utility. It expects the sibling `data` folder and
the original source-A module at the explicit local path in its source. It is
not a Colab launcher or a source downloader. Run within the delivered QA
workspace using its scientific runtime:

```bash
python review_data_v2.py --require-fixed
```

No further blocking issue was found within this limited review. These two
software checks do not establish real provider availability, dataset diversity,
authentic author consent, statistical power or R3.
